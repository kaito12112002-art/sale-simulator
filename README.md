# OH!KURAYA ご売却シミュレーション（PWA版）

## HTTPS公開（GitHub Pages）
1. GitHubでリポジトリを作成（既存リポジトリでも可）。
2. `index.html`、`sw.js`、`manifest.webmanifest`、`icons` フォルダを**同じ階層**にアップロード。
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch。公開するブランチ（通常 main）と `/ (root)` を選び Save。
4. GitHub PagesのHTTPS URLにアクセスして起動。`https://ユーザー名.github.io/リポジトリ名/` など。
5. **iPhone/iPad:** SafariでURLを開き、共有メニュー →「ホーム画面に追加」→「追加」。iOSのバージョンによって表記が異なることがあります。
6. インターネット接続中に一度アプリを読み込み、オフラインで再起動できるか機内モードでテスト。

## 安全上の注意
- 入力値はJavaScriptで計算し、サーバーには送信しません。localStorageなどへの保存処理もありません。
- ホーム画面に追加しても、キャッシュ削除、サイトデータ削除、端末設定、長期未使用などでオフライン用ファイルが消える場合があります。
- 配布したHTML単体はPCではオフライン利用できますが、iPhone/iPadのPWAとしてインストールするにはHTTPS配信が必要です。
- PWAキャッシュ対象はこのアプリの静的ファイルだけです。画面の「参照した公的資料」リンクはオフラインでは開けません。
- 印刷/PDF出力の対応状況はブラウザ・OSごとに異なります。
- GitHub Pagesが公開サイトの場合、URLを知る人はアクセスできます。認証機能は含みません。

## 更新方法
- 同じリポジトリへ新しいファイルをアップロードし、`sw.js` の `CACHE_NAME` を `...-v2` 等に変更してください。
- 現在の構成はオフライン優先なので、更新後は新しいページをオンラインで開いてから**もう一度再起動**すると新しいバージョンに切り替わります。
- ユーザー入力は保存されないため、更新・再読み込みすると消えます。
